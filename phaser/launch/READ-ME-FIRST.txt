RealmPack Phaser preview

1. Extract the entire ZIP. Keep game and phaser folders together.
2. Windows: double-click START-REALMPACK.bat in this folder.
3. The launcher opens the game in your browser. Keep its terminal open.

Requires Python 3 or Node.js. It chooses the correct serving directory
and an available local port automatically, avoiding the earlier 404 issue.

Other systems: run python3 launch.py or node launch.cjs here.
Do not double-click phaser/index.html; the game loads assets over HTTP.

Dungeon runs autosave in this browser under a separate Phaser save key.
Use Menu > Export run for a portable backup. Moving between ports or browsers
uses different browser storage; use Export/Import to carry a run across.
